- [ ] Install Python requirements and launch `python -m streamlit run app.py`.
- [ ] Generate at least 2 distinct missions with different settings; confirm generated output comes from local Ollama.
- [ ] Turn Wi-Fi off and generate a mission again (once dependencies/model are installed).
- [ ] Review the generated steps for safety and accessibility before trying them.
- [ ] Do one real, safe outdoor observation; record results honestly.
- [ ] Save a field receipt and open the ledger; download export.
- [ ] Take a screenshot or short video of mission creation, field receipt, and local record. Blur private info.
- [ ] `python -m unittest discover -s tests -v`.
- [ ] Create GitHub repository, commit/push; don't include local `data/` notes or `.venv/`.
- [ ] Replace bracketed placeholders in `DEV_SUBMISSION.md`; do not claim a demo/outdoor test before doing one.
